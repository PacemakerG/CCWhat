# 图归因诊断流程

CCWhat 将显性预检和隐性诊断分开处理：

```text
程序生成 Action Graph、Event Graph 和 precheck_findings
  -> 本地诊断 Agent 读取图路径、OpenSpec change 目录和用户反馈
  -> Agent 返回 suspicious_actions / suspicious_events 和证据引用
  -> 后端校验 Action、Event、precheck_finding 和文档引用
  -> 前端高亮可疑 Action 粗节点，并下钻到可疑 Event
```

- `precheck_findings`：P0 程序规则确认的显性异常事实，例如产物缺失、验证失败、验证过期。
- `suspicious_actions`：诊断 Agent 判断的可疑粗图节点。
- `suspicious_events`：诊断 Agent 判断的可疑细图事件。
- `precheck_finding_ids` 和 `document_refs`：可疑 Action 的诊断依据，不是新的可疑节点。

后端只检查引用是否真实存在，不判断模型诊断是否正确。前端保持“粗图定位 -> 点击 Action -> 细图下钻”的现有交互，不把 OpenSpec 文档或 `precheck_finding` 加入图中。
